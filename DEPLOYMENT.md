# DealLens AI — Final Release Package

## What is included
- Responsive web/PWA frontend
- Product search and Deal Score demo engine
- Image upload/preview flow
- Sell Faster listing generator
- Merchant dashboard foundation
- Node.js API foundation
- Privacy and Terms pages
- PWA manifest/service worker

## Important
This release is a production-ready project foundation, not a live marketplace by itself. Real product prices, affiliate commissions, AI vision, authentication, payments, ads, and merchant feeds require external provider accounts/API keys and a production backend.

## Local run
1. Install Node.js 18+.
2. Run `npm install`.
3. Run `npm start`.
4. Open the local address shown by the server.

## Recommended production sequence
1. Deploy API/backend.
2. Add PostgreSQL (or another managed database).
3. Connect an approved AI vision provider.
4. Connect product/merchant feeds and affiliate programs.
5. Add authentication and secure user sessions.
6. Add subscription billing for DealLens Pro.
7. Add ad network only after approval.
8. Add analytics, consent, abuse protection, rate limiting, logging, backups and monitoring.
