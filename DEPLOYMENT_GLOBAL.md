# Global Commercial Deployment

1. Keep GitHub Pages as the public frontend.
2. Upload the root files from this package to the `main` branch of `Agel-uk/deallens-ai`.
3. Do not upload real affiliate IDs, API keys, bank details, IBANs, passwords, or payment secrets.
4. Connect a secure backend later for affiliate APIs, AI, authentication, subscriptions, merchant billing and analytics.
5. Configure each approved affiliate program using its own dashboard. Amazon OneLink can simplify some international routing; other marketplaces may require separate accounts.
6. Use your UAE bank account only inside the payment/affiliate provider's official payout settings when supported.
