# Publish checklist
1. Back up the current repository.
2. Upload/replace the files from this package in the repository root.
3. Keep `affiliate-config.js` with `AE: 'deallensai-21'`.
4. Commit changes to `main` and wait for GitHub Pages deployment.
5. Test Home, Buying Guides, Markets, Earnings, Privacy and Terms.
6. Search with UAE selected and confirm the Amazon.ae URL contains `tag=deallensai-21`.
7. Search with another market and confirm the correct local Amazon domain opens without a DealLens tag until that program is approved.
8. Submit `https://agel-uk.github.io/sitemap.xml` to Google Search Console.
