# DealLens AI — US-first global launch (no approved affiliate accounts)

Upload the **contents** of this ZIP to the root of Agel-uk/deallens-ai, not into a subfolder. Preserve any existing repository-specific settings. This is a staging package, not an automatic deployment.

- US/USD is the default. Visitors can manually select major marketplaces on each buying guide. The choice persists locally.
- Affiliate IDs are EMPTY by design in affiliate-config.js. All offers are ordinary Amazon marketplace searches until approved IDs are entered. No guaranteed earnings.
- 16 upgraded guides from the earlier Buying Guides 2.0 package are included.
- Canonical URLs use /deallens-ai/ and robots noindex directives were removed from HTML.
- Check GitHub Pages settings and test links after publishing.
- Existing AdSense code is not evidence of approval.
- Do not enable Amazon US OneLink until your account and OneLink enrollment permit it.
- Never insert a guessed Amazon Associates tag.
- Be aware that old browser service worker caches can serve older files; clear site data if needed.
