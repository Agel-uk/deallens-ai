# Upload to Agel-uk.github.io

Upload all files in this folder to the repository root of:
Agel-uk/Agel-uk.github.io

Then:
1. Commit directly to main.
2. Open Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Branch: main, folder: /(root), then Save.
5. Wait for the Pages workflow to complete successfully.
6. Confirm the homepage and /ads.txt are publicly accessible.
7. Return to AdSense > Sites > agel-uk.github.io.
8. Choose AdSense code snippet, check "I've placed the code", then Verify.
9. If verification succeeds, request review.
